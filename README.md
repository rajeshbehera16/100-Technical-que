## ☕ Java

### 1. What is Java?
Java is a high-level, object-oriented, class-based programming language developed by Sun Microsystems. It is widely used for web, mobile, desktop, and enterprise applications.

### 2. Why is Java platform independent?
Java code is compiled into bytecode, which runs on the JVM (Java Virtual Machine). Since JVMs are available for different operating systems, the same Java bytecode can run on Windows, Linux, or macOS (**Write once, run anywhere**).

### 3. JVM vs JRE vs JDK

| Component | Meaning | Purpose |
| :--- | :--- | :--- |
| **JVM** | Java Virtual Machine | Executes bytecode. |
| **JRE** | Java Runtime Environment | JVM + runtime libraries required to run Java applications. |
| **JDK** | Java Development Kit | JRE + development tools like compilers (`javac`), debuggers, etc. |

### 4. What is bytecode?
Bytecode is the intermediate code generated by the Java compiler (`javac`). It is stored in `.class` files and executed by the JVM.

### 5. What is OOP?
OOP stands for **Object-Oriented Programming**. It organizes software design around objects and classes.
The four main principles are:
1. **Encapsulation**
2. **Abstraction**
3. **Inheritance**
4. **Polymorphism**

## 6. Explain Encapsulation

Encapsulation means **wrapping data and methods together inside a class** and controlling access to the data.

It is usually achieved by:

- Declaring variables as `private`.
- Providing public **getters and setters** to access and modify the data.
- Controlling how the data can be accessed or changed.


## 7. Explain Abstraction

Abstraction means **hiding implementation details and showing only the necessary functionality** to the user.

It focuses on **what an object does rather than how it does it**.

Abstraction can be achieved in Java using:

- **Abstract classes**
- **Interfaces**

### Real-World Example

A common example is an **ATM**.

We can use an ATM to:

- Withdraw money
- Deposit money
- Check balance

However, we do not need to know the internal implementation of how the ATM communicates with the bank server or processes the transaction.

## 8. Explain Inheritance

Inheritance allows one class to **acquire the properties and methods of another class**.

It is an important concept in **Object-Oriented Programming (OOP)** that promotes **code reusability**.

In Java, inheritance is achieved using the `extends` keyword.

### Example

```java
class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
}

```


## 9. Explain Polymorphism 

**Polymorphism** means **one interface or method name having multiple forms**.

It allows the same method or interface to behave differently depending on the situation.

### Types of Polymorphism

There are two common types of polymorphism in Java:

1. **Compile-time polymorphism** → Method Overloading
2. **Runtime polymorphism** → Method Overriding



### Interview Answer

> **Polymorphism means one interface or method name can have multiple forms. In Java, it is mainly of two types: compile-time polymorphism through method overloading and runtime polymorphism through method overriding.**

## 10. Overloading vs Overriding

**Method overloading** and **method overriding** are both related to polymorphism, but they work differently.

### Difference Between Overloading and Overriding

| Feature          | Overloading                                    | Overriding                                        |
| ---------------- | ---------------------------------------------- | ------------------------------------------------- |
| Method name      | Same                                           | Same                                              |
| Parameters       | Different                                      | Same                                              |
| Method signature | Different                                      | Same                                              |
| Classes          | Usually same class                             | Parent-child classes                              |
| Polymorphism     | Compile-time                                   | Runtime                                           |
| Inheritance      | Not required                                   | Required                                          |
| Return type      | Cannot be the only difference                  | Same or covariant return type                     |
| Purpose          | Provides multiple ways to perform an operation | Provides a specific implementation in child class |

**Abstract class:**

* Can contain abstract and concrete methods.
* Can have constructors and instance variables.
* A class can extend only one class.

## 30. What is recursion?

Recursion occurs when a function calls itself to solve a smaller version of the same problem.

}

A recursion must have a base case.

A primary key uniquely identifies each row in a table.

A candidate key is a column or combination of columns that can uniquely identify a row.

A composite key consists of two or more columns together used to uniquely identify a row.

## 47. What is normalization?

Normalization is the process of organizing database tables to:

- Reduce data redundancy

- Avoid update anomalies

- Improve data consistency

Common normal forms:

- 1NF

- 2NF

- 3NF

## 48. Explain 1NF.

A table is in First Normal Form (1NF) when:

- Each column contains atomic values.

- There are no repeating groups.

## Bad:

```
Student | Phones
Rajesh | 123, 456
```

## Better:

```
Student | Phone
Rajesh | 123
Rajesh | 456
```

## 49. Explain 2NF.

A table is in 2NF when:

- It is already in 1NF.

- Every non-key attribute depends on the whole primary key, not just part of a composite key.

## 50. Explain 3NF.

A table is in 3NF when:


- It is in 2NF.

- Non-key attributes do not depend on other non-key attributes.

In simple terms: no transitive dependency.

An index is a database structure used to speed up data retrieval.

## Example:

```

```

## 52. What is a transaction?

A transaction is a group of database operations treated as a single logical unit of work.

Example:

```
Debit money
+
Credit money
```

Both should succeed, or the transaction should be rolled back.

## 53. What is ACID?

ACID stands for:

- A — Atomicity: All operations succeed or none do.

- C — Consistency: Database remains valid.

- I — Isolation: Concurrent transactions do not improperly interfere.

- D — Durability: Committed changes survive failures.

## 54. What is JOIN?

JOIN combines rows from two or more tables based on a related column.

Common joins:

- INNER JOIN

- LEFT JOIN

- RIGHT JOIN

- FULL OUTER JOIN

## 55. INNER vs LEFT JOIN

INNER JOIN: Returns only matching rows from both tables.


LEFT JOIN: Returns all rows from the left table and matching rows from the right table. If no match exists, right-side columns are typically NULL .

## 56. WHERE vs HAVING

## WHERE

- Filters rows before grouping.

## HAVING

- Filters groups after GROUP BY .

## Example:

```
SELECT department, COUNT(*)
FROM employees
WHERE salary > 30000
GROUP BY department
HAVING COUNT(*) > 5;
```

## 57. What is GROUP BY?

GROUP BY groups rows having the same values so aggregate functions can be applied.

```
SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```

## 58. What is ORDER BY?

ORDER BY sorts query results.

```
SELECT *
FROM employees
ORDER BY salary DESC;
```

## 59. DELETE vs TRUNCATE

## DELETE

- Removes selected rows.

- Supports WHERE .

- Usually logged row-by-row depending on DBMS.

- Can generally be rolled back when used within a transaction, depending on the database.

## TRUNCATE

- Removes all rows.


- Does not use WHERE .

- Generally faster for removing all rows.

- Exact logging/rollback behavior depends on the DBMS.

## 60. DELETE vs DROP

## DELETE:

Removes rows from a table but keeps the table structure.

## DROP:

Removes the table/database object itself, including its structure.

```
DELETE FROM students;
DROP TABLE students;
```

## 61. What is a subquery?

A subquery is a query written inside another SQL query.

## Example:

```
SELECT name
FROM employees
WHERE salary > (
SELECT AVG(salary)
FROM employees
);
```

## 62. What is a view?

A view is a virtual table based on a SQL query.

```
CREATE VIEW employee_view AS
SELECT name, salary
FROM employees;
```

It generally stores the query definition rather than a separate copy of the underlying data.

## 63. What is a trigger?

A trigger is a database procedure that automatically executes when a specified event occurs.

## Examples:

- INSERT

- UPDATE

- DELETE

## 64. Find second highest salary.


One common solution:

```
SELECT MAX(salary) AS second_highest
FROM employees
WHERE salary < (
SELECT MAX(salary)
FROM employees
);
```

Using DENSE_RANK() is another good approach when duplicate salaries need explicit handling:

```
SELECT salary
FROM (
SELECT salary,
DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
FROM employees
) x
WHERE rnk = 2;
```

## 65. Find duplicate records.

For duplicate emails:

```
SELECT email, COUNT(*) AS count
FROM employees
GROUP BY email
HAVING COUNT(*) > 1;
```

## 100. What is dynamic memory allocation?

Dynamic memory allocation means allocating memory at runtime from the heap.

In C, common functions are:

```
malloc()
calloc()
realloc()
free()
```

## Example:

```
int *arr = malloc(5 * sizeof(int));
if (arr != NULL) {
arr[0] = 10;
}
free(arr);
```

- malloc() → allocates memory

- calloc() → allocates and initializes memory to zero

- realloc() → resizes allocated memory

- free() → releases allocated memory
